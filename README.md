Projeto desenvolvido como culminância do segundo bimestre da disciplina de **Linguagem de Programação Orientada a Objetos (POO)**. O sistema consiste em uma aplicação desktop em Java para o gerenciamento de cadastros de um serviço de delivery, contando com interface gráfica interativa e persistência de dados estruturada em arquivos CSV.

## Sobre o Projeto
O objetivo principal deste projeto é aplicar os pilares da Orientação a Objetos (Encapsulamento, Herança, Polimorfismo e Abstração) em conjunto com o desenvolvimento de interfaces gráficas desktop (**Java Swing**) e manipulação de arquivos de texto para armazenamento persistente de dados.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Linguagem:** Java (JDK 17+)
* **Interface Gráfica (GUI):** Java Swing / AWT
* **Persistência de Dados:** Arquivos `.csv` (Comma-Separated Values)
* **Ambiente de Desenvolvimento:** Eclipse IDE / VS Code
* **Controle de Versão:** Git e GitHub

---

## 📦 Funcionalidades
* **Cadastro Completo:** Registro de clientes, produtos/pratos e pedidos de delivery.
* **Interface Gráfica Intuitiva:** Telas amigáveis construídas com componentes do Java Swing para inserção, consulta e listagem de dados.
* **Persistência em CSV:** Os dados cadastrados são salvos automaticamente em arquivos CSV, garantindo que as informações não sejam perdidas ao fechar a aplicação.
* **Validação e Tratamento de Erros:** Consistência de dados durante o preenchimento de formulários e operações de leitura/escrita de arquivos.
